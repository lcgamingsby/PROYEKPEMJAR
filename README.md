SETUP<br>
Clone semua ini :<br>
Frontend : https://github.com/lcgamingsby/PROYEKPEMJAR<br>
Backend : https://github.com/lcgamingsby/ProyekPemjarBE<br>
Database(akan ikut terclone karena di github backend) : collabdb.sql<br>
<br>
1. Masukan database ke phpmyadmin(disarankan) dengan nama yang sama seperti filenya<br>
2. Nyalakan XAMPP(nomor satu dan nomor dua dari atas)<br>
Untuk Frontend :<br>
3. npm install axios react-router-dom zustand socket.io-client<br>
4. npm install @uiw/react-codemirror @codemirror/lang-python (Jika bermasalah seperti muncul tanda kuning maka npm audit fix)<br>
5. npm run dev<br>
Untuk backend(requirement minimal 1.20) :<br>
6. go mod tidy<br>
7. go run main.go<br>
8. untuk mengetes tinggal buka link yang diberikan di saat npm run dev<br>
